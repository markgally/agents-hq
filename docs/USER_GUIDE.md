# AGENTS HQ User Guide

## Views

- **Office View** — seven cute characters in the isometric office. Idle agents walk, drink coffee, play arcade games, and join group activities. These are local scripts; they never call Codex.
- **Canvas View** — seven independent cards. Optional dependency wires appear only when you configure collaboration.

Click a character or card to open the same agent workspace.

## Chat

Enter sends; Shift+Enter newlines. Messages go to that agent’s persistent Codex thread. If the agent is busy, the message is queued. Stop interrupts the current turn when Codex supports it.

## Tasks and Run Everything

Save one primary assignment per agent. Use **Run Now** for that agent or **Run Everything** for all eligible assignments. Completed one-time tasks do not auto-repeat.

## Schedules

Optional per assignment. Backend-driven. Missed runs default to skip; overlapping runs default to skip.

## Approvals

When Codex asks to run a command, change files, or use an integration, AGENTS HQ shows an approval request. Nothing consequential is auto-approved by AGENTS HQ policy.

## Outputs

Only verified text and files that exist inside allowed folders are listed. AGENTS HQ does not invent paths.
